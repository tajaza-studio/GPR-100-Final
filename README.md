# Pitch

Dungeon Adventure is a turn-based RPG that takes place in a medieval fantasy setting. The game will be 2D, and consists of a series of turn based combats. You play as a party of adventurers delving into a dungeon. The target audience for this game is people who enjoy fantasy and visual novels.

# Risk Assessment

## Balancing Numbers

Likelihood: High

Threat: Medium

Description: Balancing numbers for the combat is a risk we will most likely face. To mitigate this risk, we will set aside time for game testing and balancing the feel of combat.

## UI

Likelihood: Low

Threat: High

Description: There are many UI implementations we have planned, it is possible we run into issues while working on them. Running the combat and utilizing different combinations of skills will test its functionality. If bugs and errors are found, they will need to be fixed.

## Art Assets

Likelihood: Medium

Threat: Low

Description: We plan to create our own assets for our game but this can be very time consuming, if we are not able to create our own we can use free assets. We will start working on these as soon as possible to lower the possibility of this happening.

# Team Agreement

## Part 1: Meeting Times

We will meet a minimum of one time per week until the project is due, excluding the week of Thanksgiving Break. The standard meeting time is Saturday from 11:00am to 3:00 pm. These will take place in booked study rooms (rooms TBD) and will serve as planning and group work sessions.

Everyone will try to attend these meetings. If physical attendance is not possible, members will attempt to join the meetings regardless via Google Meet links.

## Part 2: Merging

To avoid merge conflicts, all team members will work on code and demos in separate, labeled, Unity scenes. No one will work in another person’s scene without permission from the owner. We will work together to combine things.
